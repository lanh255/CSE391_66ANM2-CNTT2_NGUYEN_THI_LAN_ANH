# Bộ bài làm liên kết Câu 1 -> Câu 2 -> Câu 3

## Ý tưởng liên kết
- **Câu 1**: Dựng giao diện form Add Employee giống đề bằng **HTML + CSS**.
- **Câu 2**: Giữ nguyên giao diện Câu 1, bổ sung **Javascript** và file **data.js** để giả lập CSDL, hiển thị danh sách, thêm dữ liệu mới, kiểm tra dữ liệu nhập.
- **Câu 3**: Từ đúng giao diện và dữ liệu của Câu 2, **chuyển đổi sang ReactJS**, tách component và xử lý lại bằng state/props.

---

## Chạy từng câu

### Câu 1
Mở file:
- `bai1-html-css/index.html`

### Câu 2
Mở file:
- `bai2-js/index.html`

### Câu 3 (React)
Mở terminal tại thư mục `bai3-react` rồi chạy:

```bash
npm install
npm run dev
```

---

## Liên hệ giữa 3 câu
Cả 3 câu đều dùng cùng một bài toán **quản lý nhân viên** và cùng một giao diện **Add Employee**.

- Câu 1 chỉ làm phần nhìn.
- Câu 2 thêm logic JS và dữ liệu mẫu.
- Câu 3 viết lại chính ứng dụng đó bằng React để được điểm cao hơn.
